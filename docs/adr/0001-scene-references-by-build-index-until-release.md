# 製品版まではシーン参照をビルド番号のまま保ち、死にシーンもビルド一覧に残す

遷移(`Portal` / `TransitionEvent` の `sceneToLoad`)とセーブ(`lastSceneBuildIndex`)は
シーンをビルド番号の整数で参照している。旧体験版の終了シーン(TrialEnding、TrialEnd2)と
SampleScene をビルド一覧から外すと以降の番号がずれ、既存セーブ(Steam クラウド含む)と
約 50 シーンの遷移が壊れる。そのため Next Fest 向けの体験版(2026-10-05 ロック)では
ビルド一覧の枠を残し、到達経路だけを断つ(#662)。

シーン名参照への移行と旧セーブの読み替え、その後の削除は製品版までに行う(#668)。
風とパレスの間にごみ捨て部屋(#650)を挿入する予定があり、番号依存のままでは
挿入のたびに同じ事故が起きるため、移行は削除の前提として必須にする。

## 検討した代替案

- 今すぐ一覧から削除する。番号がずれて体験版のセーブ互換が壊れるため却下
- 一覧の末尾へ移す。位置が中間(18、19、28)にあるため、移すだけで以降の番号がずれる。却下
