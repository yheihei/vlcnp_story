# 計測記録

依頼に必要な表だけ使う。未取得を0で埋めず、確認した0件と反映待ちを区別する。

```markdown
## 計測記録 YYYY-MM-DD

- 集計期間・タイムゾーン:
- 取得時刻:
- 対象環境:
- 集計の反映状況:

### 受信確認

| イベント | Event Browser の表示件数 | 状態 |
| --- | --- | --- |
| areaEntered | 未取得 | 未確認 |

表示範囲とフィルタを記載。期間全体の集計件数とは区別する。

### エリア到達

| 段 | ユーザー数 | 前段からの離脱 |
| --- | --- | --- |
| 永遠 | 未取得 | 対象外 |
| 土 | 未取得 | 算出不能 |
| 闇 | 未取得 | 算出不能 |
| 風 | 未取得 | 算出不能 |
| trialEnd | 未取得 | 算出不能 |

### ゲームオーバー

| シーン | イベント回数 |
| --- | --- |
| 未取得 | 未取得 |

### 所見

観測から言えること、仮説、未確定の範囲を記載。
```

GitHub への投稿が明示的に依頼・許可されている場合だけ、完成した本文をファイルに保存し、`gh issue comment <issue番号> --body-file <ファイル>` で投稿する。投稿先が既存文脈で分かれば再確認は不要。

既存運用の記録先は #635、改善検討は #600、計測実装と動作確認の関連 issue は #663。「数字を見て」という依頼から #635 への投稿まで自動で広げない。単に「記録して」で保存先が不明なら、まずローカルの記録を作り、外部への投稿先が必要なときだけ確認する。
