# 素材生成のプロンプト例

依頼と参照画像に合わせて必要部分を使う。画像生成ツールの使用方法は [スプライト生成](../../generate-2d-sprite/SKILL.md) に従う。呼び出し回数、モデル、出力内部パスはテンプレートで固定しない。

## 反復する壁・地面テクスチャ

```text
添付の参考画像に合わせて、<ステージ説明>で使う<材質名>のドット絵テクスチャを生成してください。
最終用途は32×32 pxの反復タイルです。

原画は<対応する生成寸法>の正方形。<論理解像度>程度の大きなドットで描き、
上下左右へ反復できる模様にしてください。模様の周期は32ドットまたはその約数を目安にします。
1枚は1種類の材質で全面を不透明に埋め、枠線・文字・余白・局所的な強い光源を入れないでください。
色調は添付した<基準素材>に合わせてください。基準色は<必要なら色域>です。
原画の保存先は<作業ディレクトリ>/gen/_raw/<name>.png。
```

全面反復する床材なら横スクロールの正面視点を指定し、上端の縁を混ぜない。上端・角の専用タイルが必要な依頼にはこの禁止を適用しない。きれいな版と傷んだ版を作る場合は、基準となる材質と色を共有する。

原画の論理解像度は生成後に確認する。プロンプトに寸法を書くだけで正確なドット周期が保証されるとは扱わない。

## クロマキー用 Prop 原画

付属の `props_postprocess.py` を使う場合の例。最終出力は透過 PNG だが、この工程の入力はマゼンタ背景。

```text
添付したタイルの色調と画風に合わせて、<プロップ名・材質・形状>をドット絵で生成してください。
最終サイズは<w>×<h> pxです。その縦横比で、1個を中央に大きく配置してください。
背景はフラットな純マゼンタ #FF00FF。背景に影、グラデーション、模様、地面、壁を入れず、
輪郭のにじみを抑えてください。素材本体に背景色を使わないでください。
この工程では背景除去せず、原画を<作業ディレクトリ>/gen/_props/<name>.pngへ保存してください。
```

すでに透過した原画やマゼンタを含む本体には、このクロマキー用テンプレートと後処理を使わない。Props の候補は参考画像から選ぶ。たとえば荒廃した和風室内なら、雨染み、ひび割れ、建具、柱、掛け軸、蔦、瓦礫など。
