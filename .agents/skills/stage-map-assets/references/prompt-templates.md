# Codex 生成プロンプトのテンプレート

`<>` を差し替えて使う。冒頭の「最重要」ブロックは3種すべてに必ず入れる。

## 共通ヘッダ(必ず先頭に置く)

```text
【最重要・必ず守ること】
- 画像は必ず**組み込みの image_gen ツール**で生成すること。素材1種類につき image_gen を1回呼ぶ。
- **Pillow / PIL / numpy などでプログラム的に絵柄を描き起こすことは固く禁止**。ノイズ関数や矩形描画でテクスチャを合成してはいけない。
  Pillow を使ってよいのは image_gen 出力のリサイズ・寸法補正・ファイルコピーだけ。
- 最終報告で「image_gen を何回呼んだか」「$CODEX_HOME/generated_images 配下のどのファイルをどのパスへコピーしたか」を必ず明記すること。
  image_gen を使わなかった場合は正直に報告して中断すること。
```

## タイル素材(背景 / 地面)

```text
<ステージの説明。例: 和風の荒廃した武家屋敷の一室(2D横スクロールアクションゲームのボス部屋)>に使う、
Unityタイルマップ用の「<背景 / 地面>素材テクスチャ」を<N>種類、image_gen で生成してください。

【全<N>枚に共通の要件】
- 添付した参考画像と同じ系統の、手描き感のあるドット絵。<雰囲気の説明>。
- 1024x1024 の正方形。内容は「128x128ピクセルのドット絵を8倍に拡大したもの」に見えるよう、
  1ドット = 8x8ピクセルの大きめの正方形ブロックで描く。アンチエイリアス、ぼかし、写真的ディテールは避ける。
- 上下左右にシームレスにタイリングするパターン。模様の周期は32ドット(256ピクセル)またはその約数にそろえる。
- **1枚の画像には1種類の素材だけ**。他の素材(壁/床/柱/小物/キャラクター等)を混ぜない。
  額縁、枠線、グリッド線、区切り線、文字、番号、余白は描かない。画面全体を隙間なく埋める(不透明)。
- 一点にだけある目立つオブジェクト、はっきりした光源、画像全体にかかる大きな明暗のムラは作らない。
  ディテールは全体に均一にばらまく。
- **全枚数で色調(明度・彩度・色相)をそろえる**。ベースは <#RRGGBB 〜 #RRGGBB>、
  最も明るい部分でも <#RRGGBB> 程度まで。純白・純黒・鮮やかな原色は使わない。

（地面素材のときは追加）
- **横スクロールゲームの正面視点(真横から見た表面)**として描く。「床の上端のフチ」や「地面の切れ目」は描かない。
  どこを32ドット四方で切り出しても成立する均一な素材パターンにする。

【生成する<N>種類と保存先(絶対パス)】
1. <素材名>: <材質・模様・周期・色の具体的な指示>
   → <WORK>/gen/_raw/<name>.png
...

【完了条件】
- 上記パスにファイルが存在し、正方形であること。
- image_gen の呼び出し回数とコピー元パスを報告すること。
```

「きれいな版」と「傷んだ版」は別素材として両方頼む。傷んだ版は「板/壁の色味は<きれいな版>と同一にすること」と明記する。

## プロップ

```text
<ステージの説明>に置くプロップを<N>個、image_gen で生成してください。

【全プロップ共通の画風・条件】
- 添付した参考画像は、この部屋で使う既存タイルを並べたもの。**この色調・画風に厳密に合わせること**。
  ベースは <#RRGGBB 〜 #RRGGBB>、最も明るい部分でも <#RRGGBB> 程度まで。純白・純黒・鮮やかな原色は使わない。
- 手描き感のあるドット絵。1ドット=8x8ピクセル程度の大きめの正方形ブロックで描く。
- **背景は完全にフラットな純マゼンタ #FF00FF 一色**で塗りつぶす。グラデーション、影、模様、枠線、文字を背景に入れない。
  プロップの落とす影も描かない。
- プロップは**1個だけ**を画面中央に配置し、画面の8割程度を占める大きさにする。
  複数個並べたり、地面や壁を描き込んだりしない。
- マゼンタ背景とプロップの間に中間色のにじみができるだけ出ないよう、輪郭をはっきりさせる。
- 背景除去や縮小は不要。image_gen が出した画像をそのまま指定パスへコピーするだけでよい。

【生成する<N>個】
1. <プロップ名>: <形状・材質・色の具体的な指示>。**<縦長(横1:縦2) など比率の指示>**。
   → <WORK>/gen/_props/<name>.png
...

【完了条件】
- 上記パスにファイルが存在すること。
- image_gen の呼び出し回数とコピー元パスを報告すること。
```

比率は最終的な `w`/`h` に合わせて指示する。指示しないと正方形で返ってきて、切り詰め後に余白が大きくなる。

## プロップのグループ例(荒廃した和風屋内の場合)

| グループ | 例 |
| --- | --- |
| 壁の汚れ・傷み | 雨だれのシミ(小/大)、ひび割れ(細/太)、壁の穴(下地が覗く)、苔・カビのパッチ |
| 建具 | 障子の引き戸、破れた障子、角柱、欄間の透かし彫り |
| 装飾 | 掛け軸、石灯籠、龍の木彫り |
| 荒廃・自然侵食 | 垂れ下がる蔦、下草、崩れた木材と瓦礫、折れて落ちた梁、苔むした石 |
