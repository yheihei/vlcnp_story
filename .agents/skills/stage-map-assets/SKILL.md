# ステージ素材セット

参考画像と説明から、指定された範囲の素材を Unity で使える状態にする。セット一式の依頼では Tile・Palette・必要な Prop Prefab まで仕上げる。素材だけの依頼へプレビューシーンやステージ配置を追加しない。

範囲、素材数、名前、Props の要否は依頼と既存セットから判断する。結果を左右する不明点だけ確認する。

## 素材の構成

`bg_` はコライダーなしの背景、`ground_` は足場用。標準は 32×32 px・PPU 32。反復素材は1タイルで成立させる。端・角・連続パネルが必要なら役割を分ける。

傷みが反復して不自然になる素材では、きれいな面と傷んだ面を分ける。変種数や色域はそのステージの画風と用途に合わせる。

## 作業に応じて読む

- 新規 PNG の生成は [スプライト生成](../generate-2d-sprite/SKILL.md)。素材テクスチャやマゼンタ背景 Props を依頼するときは [プロンプト例](references/prompt-templates.md)。
- 大きい原画からの切り出し、共通パレット、クロマキーは [後処理スクリプト](references/postprocessing.md)。既に適切な PNG があればこの工程は不要。
- Tile・Palette・Prefab の Import、保存、登録は [Unity アセット化](../building-tilemap-builder/references/unity-assets.md)。

既存セットの追加・修正では GUID と手動調整を保ち、変更が必要な素材だけを作り直す。

## 完了確認

変更した素材について、寸法、単体反復の継ぎ目、隣接色、Props の透明な縁を確認する。一式を作る場合は部屋の合成などで組み合わせも見る。Unity へ組み込んだ場合は Sprite 参照、コライダー、Palette 登録と保存を確認し、PNG の生成だけで完了としない。
