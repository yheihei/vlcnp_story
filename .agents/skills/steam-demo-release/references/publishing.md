# default への公開

対象ページは [Steamworks の体験版ビルド](https://partner.steamgames.com/apps/builds/4861250)。ブラウザ操作が必要になった段階で利用可能なブラウザツールを使い、現在の UI を確認する。

1. 新 BuildID に Windows / macOS 両 Depot と期待した manifest ID が含まれることを確認する。
2. default を選び、旧 BuildID から新 BuildID への変更プレビューを確認する。
3. 公開がすでに依頼・許可されていれば続行する。公開が必要でも対象やタイミングが不明なら、対象 BuildID・default への変更・即時公開であることを示して不明点だけ確認する。ビルドやアップロードだけの依頼に、この公開工程や公開の確認を追加しない。
4. ライブ設定とブラウザの確認を進める。SMS が要求された場合だけ、ユーザー本人にブラウザへ直接入力してもらう。コードをチャットで受け取らない。
5. 最終のビルド変更確認を完了する。

公開後は再読み込みし、default が新 BuildID を指すこと、公開履歴、両 Depot を確認する。ブラウザ応答が不明でもライブ設定を連打せず、まずこの状態を照会する。

確認済みの公開結果を報告する。アップロード成功、SMS 入力待ち、変更プレビューを公開完了と混同しない。
