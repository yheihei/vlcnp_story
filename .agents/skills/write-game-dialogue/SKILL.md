# ゲーム内の会話文

指定された台詞、話者の口調、会話の順序を保つ。改行の修正だけなら、文言や句読点を勝手に書き換えない。

## 改行

- 長い台詞は自動折り返し任せにせず、文末や意味のまとまりで明示的に改行する。単語、固有名詞、助詞につながる語句、語尾の途中で切らない。
- 行頭に「。」「、」「）」などの閉じる記号が来ないようにする。「ね。」など短い語尾だけを次の行へ残さない。
- 意味の切れ目の例は「おひるねべや(永遠)を脱出したと思ったら、\n速攻でこの穴に落ちたのよ。\nふざけてるわよね。」。「気をつけて\nね。」のように分けない。
- 一律の文字数では決めない。実際のダイアログの幅、フォント、描画サイズを確認し、明示した各行がさらに自動折り返しされない長さにする。
- 短い台詞には不要な改行を加えない。表示領域に収まらない場合は、会話のテンポと演出を保って複数のSayに分ける。共通UIやフォントの変更は台詞調整とは別の判断にする。

## 実装と確認

シーン編集には [unity-editor-automation](../unity-editor-automation/SKILL.md) を使い、既存のFungus `Say.storyText` を差分更新する。文字列中の改行は実際の改行文字にする。話者・顔写真・フラグ分岐・カメラ演出は依頼に合わせる。

修正した長い台詞をPlay Modeで全文表示し、初回・再会話など対象の分岐ごとに画面を確認する。文字送り途中の画像だけで合格にしない。句読点や語尾の孤立、単語の分断、想定外の折り返し、下端の見切れを確認する。文字列の検査だけで画面確認済みとしない。

確認後はPlay Modeを終了し、対象シーンの保存状態を確認する。
