# 建物素材の調整

## 分割と配置

標準タイルは 32×32 px。3段の壁は 32×96 px を top / middle / bottom に分割できる。2タイル幅の扉・入口は 64 px 幅が目安であり、依頼の寸法を優先する。

`bg_` は壁、`ground_` は足場、`crack_overlay_` / `hole_overlay_` は傷みの素材に使える。プレビューや原画から Tile・Prefab を作らない。

枠のある壁セットでは、中央壁は四辺の外枠なし、左端は左の外枠だけ、右端は右の外枠だけを残す。枠なしの反復素材にこの処理を適用しない。最終 PNG は正確な寸法にし、ファイル名も既存規約へ合わせる。

## 継ぎ目と色

単体反復と、隣接する別タイルの組み合わせを確認する。黒線、下端の影、壁色の段差など症状に応じて調整する。端の1〜2列を周囲の壁色へ合わせる処理は、線の原因がその画素にある場合の候補であり、一律には行わない。

ひび割れ・穴は使用方法に合わせる。

- 任意の壁へ重ねる素材なら、背景を透過しつつひび割れや破片を残す。
- 周囲の漆喰・木・石などを含む壁の差分素材なら、下地を既存壁に色合わせする。
- 透過処理で細部が消える場合は原画へ戻って調整する。矩形の境界を消すために傷みの絵まで削らない。

画像編集・後処理は利用中ツールの契約に従い、変更後のタイル反復や壁への合成で結果を確認する。
