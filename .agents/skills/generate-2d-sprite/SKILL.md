# 2D スプライト生成

既存 PNG や Prefab の設定変更だけなら画像生成は不要。新しい絵柄には利用可能な画像生成ツールを使う。Codex は `imagegen` skill とツールの契約に従って直接生成する。画像生成機能を持たないエージェントが Codex CLI を使う場合だけ [CLI への委譲](references/codex-cli.md) を読む。

## 素材の条件

依頼と既存素材から次を定め、結果を左右する不明点だけ確認する。

- 最終 PNG の正確な幅・高さと、既存素材に合わせる画風。敵の基準方向は左向き。
- スプライト・プロップは RGBA で背景 alpha=0。全面を埋める壁・地面タイルは不透明。
- 出力先とファイル名。新規ファイルは既存規約に合わせて寸法を含める。既存ファイルの改訂では参照を壊す名前変更をしない。
- 原画と最終出力を分ける。生成ツールの対応寸法と最終ピクセル寸法を混同しない。

切り出し・リサイズ・色調整・透過処理は利用中ツールの制約に従う。後処理が許される場合も、元の絵を保ち、シャープなドットと必要な細線を残す。新しい絵柄の生成をノイズや仮図形で代替しない。明示された仮素材は依頼どおり扱う。

## 完了条件

保存先でファイルの存在・寸法・alpha を確認し、実画像で絵柄と輪郭を確認する。委譲した場合も成果物そのものを確認し、ログ中の特定文字列や固定の生成フォルダを成功の証拠にしない。

指定された PNG だけの依頼ならそこで完了する。Unity への組み込みまで含む場合は、対象を配置・Import して参照を確認する。
